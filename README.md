# bobis-brick
 A console I am  working for hack club's create your own console challenge. This includes a game, a controller pcb, a controller case(For the actual console I play on making it inside a suitcase) 


## Tower Game
This is the game that I created for the console.

### Controls
###### W/Space: Jump
###### A: Move Left
###### D: Move right
###### R: Reload Spells
###### Q: firebolt spell
###### E: burst spell
###### F: Super Jump spell

### About the game
In this game you defeat waves of enemies such as flying fireballs and rolling rocks as the tower keeps growing towards the sky.

## Controller
This is the pcb for the controller

### Parts
2x COM-09032 joysticks
1x Seeed Studio XIAO RP2040

## Case
This is a basic case for the controller. I intend of creating a case for the console out of a suit case once I get the physical console.

## Launcher App
This is a basic launcher app for the launcher. Currently it can launch the Tower game as well as being able to launch other apps.
